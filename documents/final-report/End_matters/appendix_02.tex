\chapter{RexRank Leaderboard}\label{app:rexrank}

The ReXrank Leaderboard is a standardized public benchmarking platform for evaluating AI-driven chest X-ray report generation and
visual question answering (VQA). It also consists of a separated leaderboard for the ReXGroundingCT dataset where the task is to
output precise 3D segmentation masks from narrative finding sentences. This leaderboard contains the private test set of the
ReXGroundingCT dataset, consisting of 100 scans.

\section{Performance Metrics}
The RexRank Leaderboard uses the following metrics to evaluate the performance of models on the ReXGroundingCT dataset:
\begin{itemize}
    \item Global Dice: Average Dice per finding per case
    \item Global HIT Rate: Proportion of findings that have Dice $\ge 0.1$
    \item Instance Precision: TP / (TP + FP), where True Positives are instances that have a Dice $\ge 0.2$
    \item Instance Recall: TP / (TP + FN)
\end{itemize}
